# MarkovChain-Online-test-and-view
You can run and view markov chains here! Generate text with a markov chain. Create or train your own markov chain free and online in a website. Saves memory in browser!
## How to run?
go to ![this webpage](https://raw.githubusercontent.com/OxillenGlow/MarkovChain-Online-test-and-view/main/index.html)
to start trying it out!
### Does it save?
Yes. If you are not in private mode you don't need to do anything. If you are in private mode, click the download or upload at the bottom of the page.
